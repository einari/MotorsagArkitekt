# MOTORSAG ARKITEKT — Amiga 500 edition

The OCS/PAL Amiga version of the Kattene demo, in **68000 assembly** —
a proper Amiga production: SoundTracker music with the classic **ST-01
instruments**, per-scanline copper skies, double-buffered blitter bobs,
and the web demo's own 3D ships as filled vectors.

## The music: a real SoundTracker module

`motorsag.mod` is a standalone, distributable ProTracker module (M.K.,
16 patterns, 4 bars each at speed 6) generated by `gen_mod.py` from the
same 64-bar arrangement both demo ports share (`../C64/gen_music.py`):

| channel | instrument (ST-01)                                     |
|---------|--------------------------------------------------------|
| 1       | SyntheBass — the octave-jumping synthwave bass         |
| 2       | Stabs — chord stabs via the 0xy arpeggio effect        |
| 3       | Leader / AnalogString — the sung lead melody and pads  |
| 4       | BassDrum2 / Snare1 / CloseHiHat — **and the vocals**   |

The vocal phrases (KATTENE, OOHH, HESTENE, "…ER FANTASTISK!") are MOD
samples cut from the AI-separated stem of the project's own track —
high-passed, compressed and normalized so they cut through, with the
bass and lead **ducking** (Cxx) underneath while a phrase sings. Four
samples cover all nine vocal placements across both verses and the
finale. Instruments are auto-tuned: each ST sample's fundamental is
measured and the sample resampled so its notes land exactly on the
ProTracker period table (which is what makes 0xy arpeggios legal), with
synthesized loop points for the sustained sounds.

The module was verified by rendering it with a Python ProTracker
simulator and chord-matching the audio bar-by-bar: **64/64 bars** match
the intended progression, vocals land on their cues. It plays in any
tracker — the demo embeds it and drives all visuals from the replayer's
song position. The replayer is a ProTracker subset (notes, Fxx, Cxx,
0xy) that follows PT's own hardware discipline: DMACON settle delays
around retriggers, repeat pointers written after the first fetch, and
held notes snapped back to their base period when an arpeggio row ends.

## The visuals

Three bitplanes, 352px-wide **double-buffered** playfields (draw into
the hidden buffer while the copper shows the other; dirty-rectangle
clears so only what moved is repainted), and a copper list with a
palette write on *every scanline*:

- **Title screen** in scale4x-smoothed 32px letters from the project's
  own font, a 96-step metallic **copper gradient rolling through the
  letters**, and a per-line sky wash behind it.
- **CRT look**: the shadow-mask pass darkens alternate scanlines and
  vignettes the frame edges — the web demo's CRT filter, done the
  Amiga way.
- **DYCP scroller**: every letter of the bottom scroller bounces on its
  own sine, blitter-drawn each frame into a cleared band.
- **The cast as blitter bobs**: 4-frame chainsaw cats, architect horses
  with big **rotating magic circles** drifting on lissajous paths,
  everyone back for the finale — per-scene copper palettes.
- **The drop is pure outrun**: a 4096-colour per-scanline sunset, a
  banded **sun** sinking through the glow, the horizon **grid with
  converging verticals** rushing toward you — and the web demo's own
  spaceship. The 3D mesh (nose cone, hull, wing) is lifted straight
  from `Spaceships.ts`, transformed per frame on the 68000 (yaw from
  the flight path's tangent, pitch and bank from the same formulas the
  web version uses), backface-culled, one XOR dot per scanline per
  edge, **blitter parity-filled** into three colour classes.
- **Copper plasma**: part two's colour-pattern is two sine fields added
  per scanline into a 32-entry RGB palette — plasma with zero bitplane
  cost, exactly the "just a pattern with colours" of the original.
- **The lyrics, sung on screen**: every line of the song appears on the
  bar its vocal lands on — the keyword big (32px) and the lines under
  it (16px), both verses, then the title is restored when the song
  loops.

```
bars  0-3   title + gradient        bars 34-50  copper plasma, verse 2
bars  4-7   copper bars, cats       bars 51-60  rainbow finale, all
bars  8-19  horses + magic circles  bars 61-63  TUSEN TAKK ... and loop
bars 20-33  sunset, sun, grid, 3D ships
```

Every scene was verified by driving FS-UAE (A500, PAL, Kickstart 1.3)
headlessly and reading back screenshots; the ship renderer additionally
has a pixel-exact Python simulator that checked 32 poses for parity
leaks before the 68000 version ran.

## Build

```bash
./build.sh
```

Needs [vasm](http://sun.hasenbraten.de/vasm/) (`make CPU=m68k
SYNTAX=mot`). Python 3 + numpy regenerate the data; `xdftool`
(`pip install amitools`) packs the disk; point `ST_DIR` at the ST-xx
sample packs to rebuild the MOD. Everything generated is committed, so
vasm alone can rebuild, and nothing is needed just to run it.

## Run

Boot **`motorsag.adf`** in FS-UAE / WinUAE (A500, PAL, Kickstart 1.3)
or on a real A500 via Gotek. The disk also carries `motorsag.mod` as a
plain file — grab it for your favourite tracker. Reset to exit.
