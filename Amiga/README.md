# MOTORSAG ARKITEKT — Amiga 500 edition

The OCS/PAL Amiga version of the Kattene demo, in **68000 assembly** —
now a proper Amiga production: SoundTracker music with the classic
**ST-01 instruments**, blitter effects, and vector ships.

## The music: a real SoundTracker module

`motorsag.mod` is a standalone, distributable ProTracker module (M.K.,
16 patterns, 4 bars each at speed 6) generated by `gen_mod.py` from the
same 64-bar arrangement both demo ports share (`../C64/gen_music.py`):

| channel | instrument (ST-01) |
|---------|--------------------|
| 1       | DXBass — the octave-jumping synthwave bass |
| 2       | PolySynth — chord arpeggios via the 0xy arpeggio effect |
| 3       | Leader — the sung lead melody |
| 4       | BassDrum2 / Snare1 / HiHat1 — **and the vocals** |

The vocal phrases (KATTENE, OOHH, HESTENE, "…ER FANTASTISK!") are MOD
samples cut from the AI-separated stem of the project's own track —
high-passed, compressed and normalized so they cut through, with the
bass and lead **ducking** (Cxx) underneath while a phrase sings. Four
samples cover all nine vocal placements across both verses and the
finale. Instruments are auto-tuned: each ST sample's fundamental is
measured and the sample resampled so its notes land exactly on the
ProTracker period table (which is what makes 0xy arpeggios legal), with
synthesized loop points for the sustained sounds.

The module was verified by rendering it with a Python ProTracker
simulator and chord-matching the audio bar-by-bar: **64/64 bars** match
the intended progression, vocals land on their cues. It plays in any
tracker — the demo embeds it and drives all visuals from the replayer's
song position (a ProTracker-subset replayer: notes, Fxx, Cxx, 0xy).

## The visuals

Three bitplanes, 352px-wide buffers (hidden spill words so blits enter
smoothly from the right), copper + blitter doing what they were born for:

- **Title screen** in scale4x-smoothed 32px letters from the project's
  own font ("KATTENE presenterer MOTORSAG ARKITEKT"), with a 44-step
  metallic **copper gradient rolling through the letters** — the classic
  Amiga logo look.
- **DYCP scroller**: every letter of the bottom scroller bounces on its
  own sine, blitter-drawn each frame into a cleared band.
- **The cast as blitter bobs** (converted straight from the C64 sprite
  art): 4-frame chainsaw cats in the first verse, architect horses +
  a drifting magic circle from the HESTENE bar, dancers and bobs in the
  tunnel, everyone in the finale — with per-scene copper palettes.
- **Vector spaceships** in the drop: CPU-computed polygon outlines
  (one XOR parity dot per scanline), **blitter-filled**, banking as
  they swoop — and the cockpit is a genuine hole in the fill parity.
- **The lyrics, sung on screen**: every line of the song appears on the
  bar its vocal lands on — the keyword big (32px) and the lines under
  it (16px), blitted into the title zone, both verses, then the title
  is restored when the song loops.
- **Copper backgrounds** per scene on the shared bar timeline: sine
  copper bars → 4096-colour sunset + rushing horizon grid → breathing
  tunnel rings → rolling rainbow finale.

```
bars  0-3   title + gradient        bars 34-50  tunnel, dancers, verse 2
bars  4-7   copper bars, cats       bars 51-60  rainbow finale, all
bars  8-19  horses + magic circle   bars 61-63  TUSEN TAKK ... and loop
bars 20-33  sunset, vector ships
```

Verified by driving FS-UAE (A500, PAL, Kickstart 1.3) from the build
scripts and reading back screenshots of each scene.

## Build

```bash
./build.sh
```

Needs [vasm](http://sun.hasenbraten.de/vasm/) (`make CPU=m68k
SYNTAX=mot`). Python 3 + numpy regenerate the data; `xdftool`
(`pip install amitools`) packs the disk; point `ST_DIR` at the ST-xx
sample packs to rebuild the MOD. Everything generated is committed, so
vasm alone can rebuild, and nothing is needed just to run it.

## Run

Boot **`motorsag.adf`** in FS-UAE / WinUAE (A500, PAL, Kickstart 1.3)
or on a real A500 via Gotek. The disk also carries `motorsag.mod` as a
plain file — grab it for your favourite tracker. Reset to exit.
